# PhantomVault

A local-first digital vault built to keep your private data on your device.

PhantomVault is a project I'm building to learn more about **web development, JavaScript, local storage, and encryption** while making something actually useful.

## Planned features

* 🔐 Master password
* 📝 Private notes
* 🔑 Passwords and secrets
* 🔎 Search
* 🏷️ Tags
* 💾 Local storage
* 🔒 Client-side encryption
* 📦 Encrypted export/import

## Philosophy

No unnecessary accounts. No random tracking. No server storing your private data.

The goal is to make a simple vault where **your data stays yours**.

## Status

🚧 **In development**

Built mainly from scratch while learning. AI is used for learning, questions, debugging, and occasional code cleanup — but the project and majority of the code are written by me.
